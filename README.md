## 📝 Descripción del Proyecto

Página Web dedicada al mundo de las miniaturas. 
Aquí vamos a ver sus orígenes y toda la info necesaria para entrar en este maravilloso mundo!

## ✨ Características Principales

*   **Diseño Responsive:** Adaptable a dispositivos móviles, tablets y computadoras de escritorio.
*   **Interfaz de Usuario (UI):** Componentes visuales modernos, limpios y fáciles de navegar.
*   **Secciones Incluidas:** MINIATURAS - PINTURAS ACRILICAS - IMPRESORAS 3D - RECOMENDACIONES.

## 🛠️ Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando el siguiente stack tecnológico:

*   **HTML5:** Estructuración del contenido web.
*   **CSS3:** Estilos, diseño visual y diseño responsivo (puedes especificar si usaste Flexbox, Grid, Bootstrap, Sass, etc.).
*   **GitHub Pages:** Alojamiento y despliegue continuo de la aplicación web.
